# 抽然动态

AstrBot 插件 —— 随机抽取嘉然全量 B站历史动态，调用 LLM 以 BOT 人设评价，并附上原动态链接与发布时间。

## 指令

| 指令 | 说明 |
|------|------|
| `/抽动态` | 从嘉然全量历史动态中随机抽取一条并发送 |

## 功能流程

1. 首次使用（或缓存过期）时，自动分页拉取嘉然全部 B站历史动态并缓存到本地
2. 日常使用时直接从本地缓存随机抽取
3. 每 6 小时自动刷新缓存，拉取最新动态
4. 解析动态内容（支持纯文字、带图、转发等类型）
5. 调用 LLM，以 BOT 当前人设从粉丝视角对动态发表简短评论
6. 输出：动态原文 + LLM 评价 + 原动态链接 + 发布时间

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `llm_provider_id_override` | string | 空 | 指定评论用的 LLM 提供商ID，留空使用当前会话默认 |
| `cache_max_age_seconds` | int | 21600 | 缓存有效期（秒），超时自动刷新，默认 6 小时 |
| `max_fetch_pages` | int | 0 | 最大拉取页数限制，0 为不限制 |

## 部署

1. 将本文件夹放入 AstrBot 插件目录
2. 安装依赖：`pip install httpx>=0.25.0`
3. 重启 AstrBot
